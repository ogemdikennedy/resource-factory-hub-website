# Resource Factory Hub — Website Version 2

## Publishing
Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and the `assets/` directory to the root of your existing GitHub repository. GitHub Pages: Settings → Pages → Deploy from branch → main → / (root).

## Version 2 changes
- Updated homepage headline and description.
- Expanded About RFH and added founder biography without a photograph.
- Changed public-facing company name to Resource Factory Hub while registration of Resource Factory Hub Limited remains in process.
- Clarified Zenodo as a publicly available research output, manuscript status as unconfirmed, and GreenMirror as under development.
- Removed survey percentages from visitor-facing copy pending verification of the survey questions.
- Kept the three original logo files unchanged.

## Editing
- `index.html`: text, research, projects and contact details.
- `styles.css`: layout and colours.
- `script.js`: navigation and email preparation.
- `assets/`: approved original logos and future photographs.

## Important
The contact form prepares an email through the visitor's email app; it does not submit data to a server. Before sharing widely, verify all research claims, dates, manuscript status and links. Do not upload confidential information to a public repository.
