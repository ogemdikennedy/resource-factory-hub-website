# Resource Factory Hub — Website Version 1

## Open and review
Open `index.html` in a browser. The site is a static, responsive, single-page website with seven navigation sections.

## Approved brand assets
`assets/RFH_Primary_Horizontal.png` is the ORIGINAL provided logo, included unchanged. `assets/RFH_Dark_Background.png` and `assets/RFH_Stacked.png` are retained unchanged. Do not redraw, alter or replace approved brand artwork.

## Edit content
- `index.html`: headings, text, research, projects, event information, links and contact details.
- `styles.css`: site colours, spacing, type and responsive design. Main hero green: `#245B46`.
- `script.js`: mobile navigation and contact email preparation.
- `assets/`: original logos and future photos. Add an `<img>` element to the relevant project/event card when photos are ready; use descriptive alt text.

## Contact form limitation
The contact form uses `mailto:` to prepare an email in the visitor's email application. It does NOT send automatically, store data, or guarantee delivery. To accept form submissions directly, configure and test a suitable external form service/backend later.

## Research accuracy and launch review
- Greenwashing assessment is NOT a QR scanning project.
- 45 survey responses and percentages relate to greenwashing research; exact survey question wording must be verified before presenting percentages as findings.
- Confirm textile manuscript status before publication.
- Confirm any dates, event roles and external links against originals.
- The initial project and event imagery is not yet supplied; use only authentic images with permission.
- GreenMirror is a developing research initiative, not a commercial deployed platform.

## Free publishing
GitHub Pages can host static HTML/CSS/JS from a public repository on GitHub Free. Upload the contents of this folder (not the enclosing folder) to a repository, then configure Settings → Pages → Deploy from a branch → main / root. Check the deployed URL and contact link. A public repository exposes website source code; do not upload private data.

## Later updates
Edit files, save and re-upload/commit to the host. Keep a backup of the entire folder. No paid builder or proprietary format is required. A future CMS may be added if dashboard editing becomes important.
